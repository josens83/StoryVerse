# ADR 002: Monetization Model

## Status

Accepted

## Context

웹소설 플랫폼의 수익 모델을 설계해야 합니다. 주요 벤치마크:

- 番茄小说 (MAU 1.92억): 무료 + 광고 하이브리드
- 阅文集团 (매출 812억위안): 유료 구독 + 코인

## Decision

### 1. 코인 시스템

- **유료 코인 (Purchased)**: 실제 결제로 구매, 무기한 유효
- **무료 코인 (Earned)**: 활동으로 획득, 30일 유효기간
- **소비 순서**: 무료 코인 → 유료 코인 (사용자 유리)

### 2. 챕터 해금 방식

| 접근 타입   | 설명                         |
| ----------- | ---------------------------- |
| `free`      | 무료 공개 (처음 N화)         |
| `ad_unlock` | 광고 시청 또는 코인으로 해금 |
| `wait_free` | 시간 경과 후 무료 (等免费)   |
| `coin`      | 코인으로만 해금              |
| `vip`       | VIP 전용 콘텐츠              |

### 3. VIP 등급

| 등급 | 일일 무료 | 기다무 시간 | 광고 스킵 |
| ---- | --------- | ----------- | --------- |
| Free | 0         | 24시간      | ❌        |
| VIP  | 5         | 12시간      | ✅        |
| SVIP | 15        | 6시간       | ✅        |

### 4. 작가 수익 배분

- 기본 50%, 등급별 최대 70%
- 독점 계약 시 +5% 보너스

## Consequences

### Positive

- 다양한 결제 옵션으로 사용자 선택권 확대
- 기다무로 무료 사용자도 유지
- 작가에게 공정한 수익 배분

### Negative

- 복잡한 비즈니스 로직
- 코인 만료 관리 필요

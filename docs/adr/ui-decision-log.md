## 2024-12-18

### 디자인 시스템 채택

**결정: shadcn/ui 기반 컴포넌트 라이브러리 사용**

- 이유: Tailwind CSS와 통합, 접근성 기본 지원, 커스터마이징 용이
- 참조: Vercel, Linear 등 현대적 SaaS 제품
- 구현: `src/components/ui/` 디렉토리에 컴포넌트 배치

### 브랜드 색상

**결정: 오렌지(#ff6b35)를 primary 색상으로**

- 이유: 웹소설 플랫폼의 따뜻하고 활기찬 분위기 표현
- 참조: 카카오페이지 (노란색), 네이버 시리즈 (초록색)과 차별화
- 구현: CSS 변수 `--primary`로 정의

### 모바일 네비게이션

**결정: 하단 탭 바 사용 (모바일)**

- 이유: 한 손 조작 편의성, 네이버 시리즈/카카오페이지 UX 패턴
- 구현: `BottomNav` 컴포넌트, md 브레이크포인트 이하에서만 표시

### 다크 모드

**결정: 시스템 설정 기본 + 수동 토글**

- 이유: 야간 독서 사용자 편의, 눈의 피로 감소
- 참조: Kindle, 리디북스
- 구현: `next-themes` 라이브러리 (미구현, 예정)

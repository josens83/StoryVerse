## 사용 예시

### 예시: "검색 기능" 추가 검토

**1. 비전 정렬**

- [x] "한 줄 정의" 부합 - 소설 탐색 편의성 향상
- [x] 핵심 가치 강화 - 편의성
- [x] "목표 NOT"에 해당 안 함

**2. 사용자 스토리**

```
As a 웹소설 독자,
I want 키워드로 소설을 검색하고 싶다,
so that 원하는 작품을 빠르게 찾을 수 있다
```

**3. 범위 정의**

- 스코프 안: 제목/작가명 검색, 실시간 필터링
- 스코프 밖: 전문 검색, 필터 조합, 검색 히스토리
- MVP: 제목 키워드 검색

**4. 성공 기준**

- [x] 100개 소설에서 검색 결과 100ms 이내
- [x] 3글자 이상 입력 시 결과 표시

**5. 의존성**

- 라이브러리: 없음 (기본 filter 사용)
- DB 변경: 없음 (기존 novels 테이블 사용)

→ ✅ 진행 승인

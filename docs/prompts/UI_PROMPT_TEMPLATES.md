## 1. 프로젝트 컨텍스트

> 대화 시작 시 이 컨텍스트를 먼저 제공하세요.

```markdown
## StoryVerse 프로젝트 컨텍스트

이 대화에서 우리는 한국형 웹소설 플랫폼 UI를 만들 것입니다.

### 기술 스택

- Framework: Next.js 16 (App Router)
- Language: TypeScript (strict mode)
- UI Library: shadcn/ui 기반 커스텀 컴포넌트
- Styling: Tailwind CSS
- State: Zustand, TanStack Query
- Form: React Hook Form + Zod

### 기존 UI 컴포넌트

@/components/ui 에서 사용 가능:

- Button (variants: default, outline, ghost, destructive, vip, coin)
- Card, CardHeader, CardTitle, CardContent, CardFooter
- Input (label, error props 지원)
- Badge (variants: default, secondary, destructive, outline)
- Modal, Tabs, Skeleton, Toast, Loading
- DataContainer (로딩/에러/빈 상태 통합)
- EmptyState (빈 상태 UI)

### 디자인 가이드라인

- 모바일 우선 반응형 (기본 → md → lg)
- 주요 색상: orange-500 (primary), gray (secondary)
- 최소 터치 타겟: 44x44px
- 접근성: WCAG 2.1 AA 준수

### 코딩 컨벤션

- 절대 경로 import (@/)
- 함수형 컴포넌트 + Hooks
- Korean 주석 OK, 변수명은 English
- 인라인 스타일 사용 금지
- 하드코딩 색상 금지

이 정보를 기억하고, 모든 컴포넌트에서 일관성을 유지해주세요.
```

## 2. 새 컴포넌트 생성

### 템플릿

```markdown
## 역할

당신은 React/TypeScript 전문 시니어 프론트엔드 개발자입니다.
클린 코드, 접근성, 성능 최적화를 중시합니다.

## 프로젝트 컨텍스트

- Framework: Next.js 16 (App Router)
- UI Library: @/components/ui (Button, Card, Input 등)
- Styling: Tailwind CSS
- Language: TypeScript (strict mode)

## 작업

[컴포넌트명] 컴포넌트를 만들어주세요.

## 기능 요구사항

- [기능 1]
- [기능 2]
- [기능 3]

## UI/UX 요구사항

- 상태: 로딩(Skeleton), 성공, 에러(메시지+재시도), 빈 상태 모두 구현
- 반응형: 모바일 우선 (기본 → md → lg)
- 애니메이션: 호버/클릭 피드백, 부드러운 전환
- 접근성: WCAG 2.1 AA (키보드, 스크린리더, 색상대비)

## 기술적 요구사항

- 기존 컴포넌트 사용: Button, Card, Input from @/components/ui
- 색상: Tailwind 토큰만 사용 (하드코딩 금지)
- 타입: Props 인터페이스 정의 + export

## 출력 형식

- 완전한 작동 코드 (복사해서 바로 사용 가능)
- TypeScript 타입 정의
- 핵심 로직 인라인 주석
- 사용 예시 코드

## 제외할 것

- 테스트 코드
- 과도한 주석
- 불필요한 div 래퍼
```

### 사용 예시: 프로필 카드

```markdown
## 작업

UserProfileCard 컴포넌트를 만들어주세요.

## 기능 요구사항

- 사용자 아바타 (기본 이미지 폴백)
- 사용자명과 VIP 등급 표시
- 팔로워/팔로잉 수 표시
- 팔로우/언팔로우 버튼
- 본인 프로필일 경우 "프로필 수정" 버튼

## UI/UX 요구사항

- 상태: 로딩(Skeleton), 성공, 에러 모두 구현
- 반응형: 모바일(세로), 태블릿+(가로) 레이아웃
- 애니메이션: 버튼 호버 효과
- 접근성: 이미지 alt, 버튼 aria-label
```

## 3. 폼 컴포넌트

### 템플릿

```markdown
## 작업

[폼명] 폼 컴포넌트를 만들어주세요.

## 필드

1. [필드명] (필수/선택, 유효성 규칙)
2. [필드명] (필수/선택, 유효성 규칙)
3. [필드명] (필수/선택, 유효성 규칙)

## 유효성 검사

- React Hook Form + Zod 사용
- 필드 blur 시 검증
- [특수 검증 규칙]

## 상태

- idle: 기본 상태
- submitting: 제출 중 (버튼 비활성화 + 스피너)
- success: 성공 메시지 또는 [동작]
- error: 서버 에러 메시지 (폼 상단)

## 접근성

- 모든 필드에 label 연결
- 에러 메시지 aria-describedby 연결
- 필수 필드 aria-required
- 에러 상태 aria-invalid
- autoComplete 속성

## 제출 핸들러

- onSubmit: (data) => Promise<void>
- 성공 시: [동작]
- 실패 시: 에러 메시지 표시
```

### 사용 예시: 회원가입 폼

```markdown
## 작업

회원가입 폼 컴포넌트를 만들어주세요.

## 필드

1. 이메일 (필수, 이메일 형식 검증)
2. 비밀번호 (필수, 8자 이상, 영문+숫자)
3. 비밀번호 확인 (비밀번호와 일치)
4. 닉네임 (필수, 2-20자, 특수문자 제외)
5. 이용약관 동의 체크박스 (필수)

## 유효성 검사

- 비밀번호는 실시간 강도 표시 (약함/보통/강함)
- 닉네임 중복 확인 버튼 (API 호출)

## 제출 핸들러

- onSubmit: (data) => Promise<void>
- 성공 시: /login으로 리다이렉트
- 실패 시: 에러 메시지 표시
```

## 4. 데이터 리스트

### 템플릿

````markdown
## 작업

[리스트명] 리스트 컴포넌트를 만들어주세요.

## 데이터 구조

```typescript
interface [ItemType] {
  id: string;
  // ... 필드 정의
}
```

## 기능

- 레이아웃: [그리드/리스트] (반응형 열 수)
- 필터: [필터 옵션들]
- 정렬: [정렬 옵션들]
- 페이지네이션: [무한 스크롤/페이지 번호]

## 상태

- loading: Skeleton [개수]개
- empty: 빈 상태 UI (메시지 + CTA)
- error: 에러 메시지 + 재시도 버튼
- success: 아이템 [레이아웃]

## 개별 아이템

- [표시할 정보 1]
- [표시할 정보 2]
- [특수 상태 표시]
````

### 사용 예시: 소설 목록

````markdown
## 작업

NovelList 컴포넌트를 만들어주세요.

## 데이터 구조

```typescript
interface Novel {
  id: string;
  title: string;
  author: string;
  coverImage: string;
  genre: string;
  rating: number;
  viewCount: number;
  isComplete: boolean;
}
```

## 기능

- 레이아웃: 그리드 (모바일 2열, 태블릿 3열, 데스크톱 4열)
- 필터: 장르 드롭다운
- 정렬: 인기순, 최신순, 평점순
- 페이지네이션: 무한 스크롤 (Intersection Observer)

## 개별 아이템

- 커버 이미지 (aspect-[3/4], lazy loading)
- 제목 (2줄 말줄임)
- 작가명
- 평점 (별 아이콘)
- 완결 표시 배지
````

## 5. 모달/다이얼로그

### 템플릿

```markdown
## 작업

[모달명] 모달 컴포넌트를 만들어주세요.

## Props

- isOpen: boolean
- onClose: () => void
- [추가 props]

## 기능

- 배경 클릭 시 닫기
- Escape 키로 닫기
- 포커스 트랩 (모달 내부에서만 Tab 이동)
- 열릴 때 첫 번째 포커스 가능 요소에 포커스
- 닫힐 때 트리거 요소로 포커스 복원

## 애니메이션

- 배경: 페이드 인/아웃
- 모달: [애니메이션 종류]

## 내용

[모달 내부 UI 설명]

## 접근성

- role="dialog"
- aria-modal="true"
- aria-labelledby (제목 연결)
- aria-describedby (설명 연결)
```

### 사용 예시: 코인 구매 모달

```markdown
## 작업

CoinPurchaseModal 모달 컴포넌트를 만들어주세요.

## Props

- isOpen: boolean
- onClose: () => void
- onPurchase: (amount: number) => Promise<void>

## 내용

1. 모달 제목: "코인 충전"
2. 코인 패키지 선택 (100/500/1000/5000 코인)
3. 각 패키지별 가격 표시
4. 보너스 코인 표시 (500+ 구매 시)
5. 결제 버튼 (variant="coin")
6. 취소 버튼

## 특수 기능

- 선택된 패키지 하이라이트
- 가장 인기 있는 패키지에 "인기" 배지
- 결제 진행 중 로딩 상태
```

## 자주 사용하는 수정 요청 문구

### 스타일 수정

```
"버튼의 패딩을 px-4에서 px-6으로 늘려줘"
"호버 시 배경색을 primary/90으로 변경해줘"
"그림자를 shadow-sm에서 shadow-md로 강하게 해줘"
```

### 레이아웃 수정

```
"모바일에서 2열을 1열로 변경해줘"
"카드 사이 간격을 gap-4에서 gap-6으로 늘려줘"
"사이드바를 왼쪽에서 오른쪽으로 옮겨줘"
```

### 애니메이션 수정

```
"전환 시간을 200ms에서 300ms로 늘려줘"
"호버 효과를 더 부드럽게 해줘 (ease-out)"
"클릭 시 scale 효과를 0.95로 추가해줘"
```

### 접근성 수정

```
"이 버튼에 aria-label='[라벨]'을 추가해줘"
"포커스 표시를 더 눈에 띄게 해줘"
"에러 메시지를 aria-describedby로 연결해줘"
```

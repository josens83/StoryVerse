# StoryVerse 프로젝트 비전

## 한 줄 정의

**한국형 웹소설 플랫폼** - 독자와 작가 모두를 위한 프리미엄 웹소설 서비스

## 대상 사용자

### 독자

- 웹소설을 즐겨 읽는 한국어 사용자
- 네이버 시리즈, 카카오페이지 등 기존 플랫폼 이용자
- 모바일/웹에서 편리하게 소설을 읽고 싶은 사용자

### 작가

- 웹소설을 연재하고 수익을 창출하고 싶은 작가
- 독자와 소통하며 작품을 발전시키고 싶은 창작자

## 해결하는 문제

| 문제                      | 해결책                           |
| ------------------------- | -------------------------------- |
| 기존 플랫폼의 높은 수수료 | 작가 친화적 수익 분배            |
| 복잡한 UI/UX              | 직관적이고 깔끔한 인터페이스     |
| 느린 로딩 속도            | Next.js SSR/SSG로 빠른 성능      |
| 불편한 결제 시스템        | 간편한 코인 충전 및 구독 시스템  |
| 독자-작가 소통 부재       | 댓글, 팔로우, 알림 시스템        |
| 작품 발견의 어려움        | 추천 알고리즘, 랭킹, 검색 시스템 |

## 핵심 가치 (3개)

1. **편의성** - 어디서든 쉽게 웹소설을 읽고 쓸 수 있는 플랫폼
2. **공정성** - 작가에게 정당한 수익을 보장하는 투명한 시스템
3. **커뮤니티** - 독자와 작가가 함께 성장하는 생태계

## 🚫 목표 NOT (명시적으로 하지 않을 것)

- **네이티브 모바일 앱** - 웹 반응형으로 충분, 앱 개발은 추후 검토
- **실시간 채팅** - 댓글 시스템으로 대체
- **AI 글쓰기 도구** - 플랫폼의 핵심 가치에서 벗어남
- **오디오북/TTS** - 초기 버전에서 제외
- **다국어 지원** - 한국어 시장에 집중
